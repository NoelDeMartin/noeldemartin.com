# Noel De Martin's Programming Skills

Noel De Martin publishes a curated collection of agent skills for software architecture and programming patterns.

## Source Repository

The canonical repository for these skills is hosted on GitHub:

- **Repository:** https://github.com/noeldemartin/skills
- **Blog Overview:** https://noeldemartin.com/blog/programming-patterns

## Installation

Install the skills in your agent environment using `skills.sh`:

```sh
npx skills@latest add noeldemartin/skills
```
